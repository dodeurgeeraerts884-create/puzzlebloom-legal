# Puzzle Bloom legal site

Static privacy policy, terms, and support page for Puzzle Bloom Android (`com.puzzlebloom.game`).

Serve locally with `python3 -m http.server 8080`, then open `http://localhost:8080/`.

GitHub Pages: deploy the `main` branch from `/(root)`. App links should use the published `#privacy` and `#terms` anchors. Review this policy whenever app SDKs, permissions, data use, or the operator change.
